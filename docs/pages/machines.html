What we're proposing

An excavator listing that starts from the job rather than the model number. The current range shows by default, every card uses the same three specs, the filters describe the work (size, dig depth, application, availability) and stock says which branch it is at. A three-question finder narrows the range for people who don't know the difference between a 320 GC and a 320 GX, which is most people.

Why

  • The live listing mixes the current range with models like the 320C L and 385C, so a buyer can spend time comparing machines Mantrac no longer sells new.
  • Cards use different labels for the same thing ("Dig Depth", "Maximum Digging Depth") and dotted thousands, so 3.050 kg reads as three kilograms.
  • The filters are Brand (one option), Engine Model (19, with duplicates) and three weight bands. None of them is how a contractor thinks about the job.
  • The listing says "Stock on demand" while the product page says "In stock" for the same machine.

Cat excavators

From 3-tonne mini excavators for utilities work to 45-tonne machines for quarries. Stock is shown by branch; anything not in stock can be ordered, and we'll tell you the lead time before you ask for a price.
